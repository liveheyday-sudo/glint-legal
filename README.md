# glint-legal

Static legal pages for the Glint iOS app, served by GitHub Pages from `main` (root).

- `/` — index
- `/privacy/` — Privacy Policy (published only once owner facts are final)

Terms of Use: Apple Standard EULA — https://www.apple.com/legal/internet-services/itunes/dev/stdeula/

Plain HTML/CSS. No cookies, analytics, scripts, or build step.
